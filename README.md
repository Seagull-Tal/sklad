# Sklad — консольное приложение для учета запчастей и заказов

## Описание

Консольное приложение для учета запчастей на складе сервисного центра и регистрации заказов на ремонт.
Проект реализован на Java с использованием JDBC и паттерна DAO.
Для хранения данных используется база данных SQLite.

## Технологический стек

* Java 17
* Maven
* JDBC (без Hibernate/JPA)
* SQLite (драйвер sqlite-jdbc)
* SLF4J (логирование ошибок БД)

## Архитектура (DAO Pattern)

Проект разделен на слои:

* **Model** — классы `Part`, `Order`
* **DAO** — интерфейсы `PartDAO`, `OrderDAO`
* **DAO Impl** — реализации через JDBC (`PartDAOImpl`, `OrderDAOImpl`)
* **Service** — бизнес-логика (`OrderService`)
* **View/Controller** — консольное меню в `Main`
* **Util** — работа с БД (`DBUtil`, `DBInit`)

## Функциональность

* Добавление запчастей на склад
* Просмотр всех запчастей
* Поиск запчастей по названию (SQL LIKE)
* Оформление заказа с транзакцией (списание запчастей + создание заказа в одной транзакции)
* Просмотр заказов по статусу
* Настройки подключения к БД вынесены в `db.properties`

## Работа с БД

DDL (создание таблиц) выполняется автоматически при старте приложения в классе `DBInit`.
Подключение к БД выполняется через `DBUtil`, настройки берутся из файла `db.properties`.

## Запуск

1. Установить JDK 17
2. Открыть проект в IntelliJ IDEA
3. Запустить `Main.java`
4. Работать с приложением через консольное меню

## Пример использования

1. Добавить запчасть
2. Найти запчасть по названию
3. Оформить заказ
4. Проверить изменение количества на складе и создание заказа
